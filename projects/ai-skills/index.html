For Pi, OpenCode, and Claude Code users ​

This collection contains reusable agent guidance, not a replacement for your project instructions or judgment. Start with one useful request. Add a companion only when it answers a real need.

New to the collection? Choose a starting point, then install only the skills you choose.

Already working? Choose a project workflow for planning, implementation, debugging, documentation, or debloating. You can also find a skill by name. You can stop at research, a specification, a task plan, a skeleton, or review findings.

Guidance is not permission ​

A listed skill is not installed. A useful companion is not a required dependency. A task list is not permission to execute, and a successful review is not permission to merge or release.

Learn the relationship types before treating arrows as a workflow contract.
