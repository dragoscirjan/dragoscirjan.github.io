The shortest safe trial ​

From a Git repository with a committed HEAD and tracked changes:

sh
redline review --harness echo --indexing disabled

echo checks the review workflow without a model, API key, or indexer. It always produces a clean answer, so it does not tell you whether the code has defects. The first-review guide includes a disposable example and the source-checkout command.

What Redline does ​

Redline captures the selected Git change, reviews eligible files, validates the structure and diff evidence of findings, and writes review artifacts. It does not apply fixes or execute the reviewed repository's code, tests, or installers. Model findings still need human review.

GitHub Actions can also publish validated findings and a managed summary when publication credentials are configured. Other forges, editor integrations, a container sandbox, and managed local model runtimes are not implemented. See the architecture reference for those boundaries.
