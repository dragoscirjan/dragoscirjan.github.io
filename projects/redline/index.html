RedlineAI code reviews for your Git changes

Review local work or automate pull request reviews with Pi or OpenCode and your choice of model. Read findings in the terminal and keep JSON and Markdown reports.

Quick start ​

Install Redline and connect Pi or OpenCode to a model. Then run this from a Git repository with a commit and tracked changes. Model reviews send captured source to your selected provider and can incur charges.

sh
redline review --indexing disabled

Read findings and coverage in the terminal, then open reviews/review.md in the output directory printed by Redline. --indexing disabled keeps the first run independent of optional indexer setup.

Next steps ​

What Redline does ​

Redline captures your change, reviews eligible files and checks findings against the diff. It does not execute the reviewed code or apply changes. Review suggestions before acting on them.

For planned integrations and upcoming work, see the roadmap.

No-key setup check ​

Prefer to check setup before connecting a model? After installation, run:

sh
redline review --harness echo --indexing disabled

echo makes no model request and always returns a clean answer. It checks the workflow, not code quality. The first-review guide includes a disposable example.
